# Enterprise RAG Assistant

An enterprise Retrieval-Augmented Generation (RAG) assistant designed to securely answer questions from internal organizational documents.

## Planned Capabilities

- Retrieval-Augmented Generation
- Role-Based Access Control (RBAC)
- Document-level access control
- PII and sensitive-data protection
- Out-of-scope question detection
- Prompt-injection protection
- Vector search
- LLM-powered responses
- Ragas evaluation
- LangSmith tracing and monitoring
- Token and cost monitoring
- Automated evaluation
- Azure deployment
- CI/CD

## Technology Stack

- Python
- FastAPI
- LangChain
- Docling
- Qdrant
- Groq
- Streamlit
- Ragas
- LangSmith
- Docker
- Microsoft Azure
